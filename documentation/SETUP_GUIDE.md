# Довідник з інсталяції та запуску 


##  Необхідні інструменти

Для повноцінної роботи з сервісом вам знадобляться:
1. **Сучасний веб-браузер:** Google Chrome, Mozilla Firefox, Apple Safari або Microsoft Edge (останніх версій).
2. **Персональний акаунт:** Потрібно зареєструвати обліковий запис у системі (або мати Google/Apple ID).
3. **Підключення до мережі Інтернет:** Для первинного завантаження даних та синхронізації бронювань.

---

## Кроки встановлення та запуску

### Варіант 1: Використання веб-версії (SaaS)
1. Відкрийте браузер та перейдіть за адресою `https://travel-planner.example.com`.
2. Натисніть **"Увійти"** або **"Зареєструватися"**.
3. Після підтвердження пошти ви потрапите у персональний кабінет.
